# Unify — EdTech Demo

**Birinchi qadamdan qabulgacha.**

Profili yo'q, nima qilishni bilmaydigan o'quvchi uchun maqsad → yo'l xaritasi → kunlik reja → portfolio seyfi.

## Ishga tushirish
1. Papkani VS Code'da oching
2. `index.html` faylini brauzerda oching (yoki Live Server bilan)
3. "Boshlash" tugmasini bosing → onboarding → dashboard

## Demo rejim
Agar onboardingni o'tkazmasdan to'g'ridan-to'g'ri `dashboard.html`ni ochsangiz, demo ma'lumotlar avtomatik yuklanadi.

## Reset
Dashboard → Profil → "Barcha ma'lumotlarni o'chirish"

## Texnologiyalar
- Vanilla HTML/CSS/JS
- localStorage (persistence)
- Glassmorphism + animated gradients
- Lucide icons (CDN)
